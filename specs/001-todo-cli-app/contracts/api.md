# API Contracts: ToDo CLI App\n\n## Endpoints\n\n### 1.  Add Task\n\n-   **Method**: `todo add`\n-   **Input**: \n    -   `title`: (string, required) The title of the task.\n-   **Output**: \n    -   Success: Task added message and the task details.\n    -   Error: Error message if the title is empty.\n\n### 2.  List Tasks\n\n-   **Method**: `todo list`\n-   **Input**: None\n-   **Output**: \n    -   Success: A list of tasks with IDs, titles, and completion status, or a message indicating the list is empty.\n\n### 3.  Update Task\n\n-   **Method**: `todo update`\n-   **Input**: \n    -   `id`: (integer, required) The ID of the task to update.\n    -   `title`: (string, required) The new title for the task.\n-   **Output**: \n    -   Success: Task updated message.\n    -   Error: Error message if the ID is invalid or the title is empty.\n\n### 4.  Delete Task\n\n-   **Method**: `todo delete`\n-   **Input**: \n    -   `id`: (integer, required) The ID of the task to delete.\n-   **Output**: \n    -   Success: Task deleted message.\n    -   Error: Error message if the ID is invalid.\n\n### 5.  Complete Task\n\n-   **Method**: `todo complete`\n-   **Input**: \n    -   `id`: (integer, required) The ID of the task to mark as complete.\n-   **Output**: \n    -   Success: Task marked as complete message.\n    -   Error: Error message if the ID is invalid.
