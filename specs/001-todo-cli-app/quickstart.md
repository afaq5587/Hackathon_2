# Quickstart Guide: ToDo CLI App\n\n## Installation\n\n1.  Make sure you have Python installed (version 3.7 or higher is recommended).\n2.  Clone the repository (if applicable).\n3.  Navigate to the project directory.\n\n## Usage\n\n1.  Run the CLI tool from the command line using `python <your_cli_file.py>` (replace `<your_cli_file.py>` with the name of your main Python file).\n2.  Use the following commands:\n    -   `todo add "<task title>"`: Adds a new task with the specified title.\n    -   `todo list`: Lists all existing tasks.\n    -   `todo update <task_id> "<new title>"`: Updates the title of the task with the given ID.\n    -   `todo delete <task_id>`: Deletes the task with the given ID.\n    -   `todo complete <task_id>`: Marks the task with the given ID as complete.\n\n## Examples\n\n-   `python todo.py add "Buy groceries"`\n-   `python todo.py list`\n-   `python todo.py update 1 "Pay bills"`\n-   `python todo.py delete 2`\n-   `python todo.py complete 3`
